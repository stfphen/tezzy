
# TEZZY.ca Website Handoff

## Goal
Build a production-ready Next.js 15 + TypeScript + Tailwind CSS website matching the supplied mockups as closely as possible.

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- React Hook Form + Zod
- Lucide Icons
- next/image

## Brand
- Soft pastel pink, cream, white.
- Rounded UI.
- Cute premium aesthetic.
- Plush teddy + bunny mascots.
- Script logo from reference.

## Event Booking Section
Lead capture form with:
- Name
- Email
- Phone
- Event type (Birthday, Bachelorette, Wedding, Baby Shower, Market, Corporate, Festival, Other)
- Date
- Guest count
- City
- Indoor/Outdoor
- Budget
- Notes

Submit to API route and support Resend/email or webhook placeholder.
